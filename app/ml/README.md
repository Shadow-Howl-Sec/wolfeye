# app/ml — Machine Learning Module (Member B)

This directory is owned by **Member B**.

## Responsibilities
- Train the Isolation Forest anomaly scoring model on enriched IOC data.
- Serialize the trained model to `model.joblib`.
- The Flask backend loads `model.joblib` at startup via `predict.py`.

## Files

| File | Purpose |
|---|---|
| `predict.py` | Scoring interface used by the Flask app — loads model, exposes `score(features)` |
| `train.py` | Standalone training script — run once to produce `model.joblib` |
| `features.py` | Feature extraction helpers shared between training and inference |
| `model.joblib` | Serialized trained model *(git-ignored, generated by `train.py`)* |
| `notebooks/eda.ipynb` | Exploratory data analysis notebook |
| `notebooks/training.ipynb` | Model training walkthrough notebook |

## How to train

```bash
# From the repo root, with the virtual environment active:
python -m app.ml.train
```

The script will:
1. Pull all enriched IOCs from the database.
2. Extract features via `features.py`.
3. Fit an `IsolationForest` on the feature matrix.
4. Save the model to `app/ml/model.joblib`.

## Feature Schema

The model currently uses these numeric features per IOC:

| Feature | Source |
|---|---|
| `vt_detections` | VirusTotal — number of AV detections |
| `vt_reputation` | VirusTotal — community reputation score |
| `abuseipdb_score` | AbuseIPDB — abuse confidence score (0–100) |
| `shodan_port_count` | Shodan — number of open ports |
| `ioc_age_days` | Days since `first_seen` |

## Notes
- Do **not** commit `model.joblib` to git (it is `.gitignore`d).
- Pin `scikit-learn` version in `requirements.txt` to avoid joblib ABI mismatches.
